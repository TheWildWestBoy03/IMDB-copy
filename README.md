To run this application, clone the repository, no matter the operating system you are using on your machine.
  - Then, go to the IMDB-React-Project folder, where you should find the src folder, with all code.
  - The application should run without any dependency needed, all of them are included within the project.
  - Run the front-end using the command npm run dev.
  - Run the api gateway using: npx nodemon .\src\backend\server.js
  - Run the user authentication microservice using the command: npx nodemon .\src\backend\authenticationMicroservice\server.js
  - Run the watchlist microservice using the command: npx nodemon .\src\backend\watchlistMicroservice\server.js
  - Run the review microservice using: npx nodemon .\src\backend\reviewMicroservice\server.js
  - Run the watch history microservice using: npx nodemon .\src\backend\watchHistoryMicroservice\server.js
  - Run the production microservice with: npx nodemon .\src\backend\productionMicroservice\server.js
